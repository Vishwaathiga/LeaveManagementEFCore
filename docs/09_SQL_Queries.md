# 9. SQL Queries

> **Important:** The following queries are illustrative SQL Server queries based on the model properties shared. The exact schema generated by EF Core can differ depending on migrations and model configuration. Check the actual database before using these as a schema replacement.

## 9.1 Create Database

```sql
CREATE DATABASE LeaveManagementEFCoreDB;
GO

USE LeaveManagementEFCoreDB;
GO
```

## 9.2 Create Employees Table

```sql
CREATE TABLE Employees
(
    EmployeeId INT IDENTITY(1,1) PRIMARY KEY,
    EmployeeName NVARCHAR(MAX) NOT NULL,
    Email NVARCHAR(MAX) NOT NULL,
    Department NVARCHAR(MAX) NOT NULL,
    IsActive BIT NOT NULL DEFAULT 1
);
```

## 9.3 Create LeaveTypes Table

```sql
CREATE TABLE LeaveTypes
(
    LeaveTypeId INT IDENTITY(1,1) PRIMARY KEY,
    LeaveTypeName NVARCHAR(MAX) NOT NULL,
    MaximumDays INT NOT NULL,
    IsActive BIT NOT NULL DEFAULT 1
);
```

## 9.4 Create LeaveRequests Table

```sql
CREATE TABLE LeaveRequests
(
    LeaveRequestId INT IDENTITY(1,1) PRIMARY KEY,
    EmployeeId INT NOT NULL,
    LeaveTypeId INT NOT NULL,
    StartDate DATETIME2 NOT NULL,
    EndDate DATETIME2 NOT NULL,
    Reason NVARCHAR(MAX) NOT NULL,
    Status NVARCHAR(MAX) NOT NULL DEFAULT 'Pending',
    AppliedDate DATETIME2 NOT NULL DEFAULT GETDATE()
);
```

## 9.5 Create LeaveBalances Table

```sql
CREATE TABLE LeaveBalances
(
    LeaveBalanceId INT IDENTITY(1,1) PRIMARY KEY,
    EmployeeId INT NOT NULL,
    LeaveTypeId INT NOT NULL,
    TotalDays INT NOT NULL,
    UsedDays INT NOT NULL,
    RemainingDays INT NOT NULL
);
```
